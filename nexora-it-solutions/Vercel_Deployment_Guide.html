Step-by-Step Vercel Hosting Guide (100% Free Forever with Custom Domain & Free SSL)

Step 1: Sign Up for GitHub

Create a Free GitHub Account & Repository

  1. Open your browser and navigate to https://github.com.
  2. Sign in, or click Sign Up if you don't have an account yet.
  3. In the top-right corner of GitHub, click the + icon → select New repository.
  4. Enter Repository name: d-tech-computer-system.
  5. Choose Public (or Private), then click Create repository.
Step 2: Upload Files

Upload Website Files to GitHub

  1. On your newly created GitHub repository page, click the link: "uploading an existing file".
  2. Open your folder: d:\Web App\nexora-it-solutions\nexora-it-solutions
  3. Drag and drop the following files into the GitHub upload area:
    • index.html
    • vercel.json
    • css/ folder
    • js/ folder
    • assets/ folder
    • README.md
  4. Scroll down and click the green "Commit changes" button.
💡 Pre-packed ZIP: A pre-packaged ZIP archive D-Tech-Computer-System-Website.zip has also been generated in your folder containing all required files!
Step 3: Deploy on Vercel

Import & Deploy on Vercel (Under 60 Seconds)

  1. Go to https://vercel.com.
  2. Click Log In → Choose Continue with GitHub.
  3. In your Vercel Dashboard, click "Add New..." → select "Project".
  4. Under Import Git Repository, click "Import" next to d-tech-computer-system.
  5. Settings check:
    • Framework Preset: Other
    • Root Directory: ./
    • Build Command: (Leave blank - static site needs 0 build steps)
  6. Click the big blue Deploy button!
🎉 Within 30 seconds, Vercel will give you a live global link: https://d-tech-computer-system.vercel.app with free automatic HTTPS security!
Step 4: Custom Domain (Optional)

Connect Your Custom Domain

  1. In your Vercel Project Dashboard, click Settings → Domains.
  2. Enter your domain name (e.g., dtechcomputers.lk or dtech.com) and click Add.
  3. Vercel will show you the exact DNS records to add at your domain provider (e.g. CNAME or A Record).
  4. Once added, Vercel automatically generates a free SSL certificate for your domain within minutes!
